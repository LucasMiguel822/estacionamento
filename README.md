# 🚗 Garagem de Carros — Sistema de Gerenciamento de Estacionamento

## 📋 Sobre o Projeto

O **Garagem de Carros** é um projeto acadêmico de prototipagem de alta fidelidade que apresenta a interface de um sistema de gerenciamento de estacionamento.

O protótipo foi desenvolvido com o objetivo de representar visualmente as principais funcionalidades de um estacionamento, incluindo o controle de veículos, o gerenciamento de vagas, o cadastro de clientes e funcionários e o registro de entradas e saídas.

A proposta é oferecer uma interface organizada e intuitiva, facilitando a compreensão dos processos que poderão ser implementados em uma futura versão funcional do sistema.

## 🎯 Objetivos

- Desenvolver um protótipo visual para um sistema de gerenciamento de estacionamento.
- Organizar as funcionalidades em uma interface intuitiva e de fácil compreensão.
- Representar a ocupação e a disponibilidade das vagas.
- Demonstrar os processos de entrada e saída de veículos.
- Planejar a estrutura e a experiência de uso do sistema antes de sua implementação.

## ⚙️ Funcionalidades Representadas

- 🔐 **Login:** tela de acesso ao sistema.
- 🏠 **Menu principal:** painel inicial com um resumo das informações do estacionamento.
- 🚘 **Registro de entrada:** interface para registrar a entrada de veículos.
- 🚗 **Registro de saída:** interface para consultar registros e representar a confirmação da saída de veículos.
- 👥 **Cadastro de clientes:** formulário destinado à organização dos dados dos clientes.
- 📊 **Relatórios:** representação visual de informações e registros do estacionamento.
- 🧑‍💼 **Cadastro de atendentes:** interface para cadastrar funcionários e organizar seus dados de acesso.
- 🅿️ **Visualização de vagas:** representação visual das vagas ocupadas e disponíveis.

> **Observação:** as funcionalidades descritas são representações presentes no protótipo e não necessariamente correspondem a recursos funcionais implementados.

## 🎨 Tipo de Projeto

**Protótipo de alta fidelidade**

Um protótipo de alta fidelidade é um modelo visual detalhado que se aproxima da aparência do sistema final. Ele permite demonstrar a organização das telas, os elementos da interface e os possíveis fluxos de navegação antes do desenvolvimento da aplicação.

Neste projeto, a prototipagem foi utilizada para planejar a interface e apresentar como um sistema de estacionamento poderá ser organizado.

## 🛠️ Ferramentas Utilizadas

- **Canva:** criação e elaboração dos elementos visuais do projeto.
- **Google Docs:** documentação, planejamento e organização das informações.

## 📚 Finalidade Educacional

O projeto foi desenvolvido como atividade acadêmica, com foco no planejamento de sistemas, na prototipagem de interfaces e na identificação das principais funcionalidades de uma aplicação.

A atividade contribuiu para a compreensão das etapas iniciais do desenvolvimento de sistemas, especialmente a organização dos requisitos e a representação visual de uma solução tecnológica.
